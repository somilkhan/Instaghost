# InstaGhost
A monochrome, liquid-glass LSPosed module for Instagram.

## Install
1. Build in Android Studio, or use a release APK, and install it.
2. In LSPosed, enable InstaGhost and scope it to Instagram.
3. Force stop Instagram, then open it.
4. Long-press the search tab to open the menu.

See PLAN.md for the roadmap. See DISCLAIMER.md before use.

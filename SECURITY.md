# Security policy

## Scope
This policy covers the InstaGhost repository, its Android companion/module code, build scripts, and published artifacts.

## Reporting
Please do not publish exploitable details in public issues. Use GitHub's private vulnerability reporting feature if it is enabled for this repository. If it is unavailable, contact the repository maintainer privately through a verified contact listed on the repository profile.

Include a concise description, impact, reproduction context that does not expose private data, and any proposed mitigation.

## Privacy expectations
- Do not attach Instagram account data, private messages, tokens, session files, or personal identifiers.
- Redact screenshots and logs before sharing.
- Diagnostic data should be minimal and local by default.

## Response
The maintainer will assess reports, reproduce where possible, and document mitigations or releases. Do not assume a report is acknowledged until you receive a response.

## Supported scope
The project is experimental. Security reports are welcome, but no supported release or device matrix is currently established.
